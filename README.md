# ☁️ Azure Full Stack Deployment Project

## 🚀 Project Overview

This project demonstrates the deployment of a full-stack web application on Microsoft Azure using scalable and secure cloud infrastructure.

It includes real-world implementation of virtual machines, networking, load balancing, and HTTPS-based secure deployment.

---

## 🧩 Architecture

* 🌐 Frontend VM (Web Server)
* ⚙️ Backend VM (Application Server)
* 🔐 Jump Server (Secure SSH Access)
* 🔄 Azure Load Balancer
* 🌍 Virtual Network (VNet + Subnets)
* 📈 Virtual Machine Scale Set (VMSS)

---

## 🛠️ Technologies Used

* ☁️ Microsoft Azure
* 💻 Linux (Ubuntu)
* 🌐 Apache Web Server
* 🗄️ MySQL
* 🔐 SSH, Networking, Load Balancing
* 🔒 HTTPS & SSL Configuration

---

## ⚙️ Key Features

* ✅ Multi-VM architecture (Frontend, Backend, Jump Server)
* ✅ Secure SSH access via Jump Server
* ✅ Load Balancer configuration
* ✅ Auto-scaling setup using VMSS
* ✅ HTTPS enabled using SSL certificate
* ✅ Network isolation using VNets and subnets
